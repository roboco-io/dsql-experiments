## 확인할 질문

DSQL의 SLO 용량·지연은 각 대조군의 몇 배인가?

## 측정 결과

아직 실험을 실행하지 않았습니다. 성능 수치, 운영 작업 시간, 비용과 결론은 측정·검토를 마친 뒤 공개합니다.

## 실험 범위와 방법

[전체 계획의 E002 항목](https://github.com/roboco-io/rds-experiments/blob/main/EXPERIMENT_PLAN.md#e002)에서 대상 구성, 방법, 지표와 판정 기준을 확인할 수 있습니다. [연결된 이슈](https://github.com/roboco-io/rds-experiments/issues/2)에서 실행 준비와 진행 상황을 관리합니다.

같은 업무·정합성·SLO를 기준으로 DSQL과 대조군을 비교합니다. 원본 로그 대신 검토한 요약을 공개하고, 실험용 리소스가 모두 삭제되었음을 확인한 뒤 완료 상태로 전환합니다.
